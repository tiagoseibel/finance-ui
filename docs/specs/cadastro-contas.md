# Cadastro de contas

# Estrutura
Lista de contas cadastradas (permitir ordendar): Mostrar nome
Botão para incluir nova conta (com icone)

# Comportamentos
Quando abrir o componente, então listar contas cadastradas
Quando clicar sobre uma linha então detalhar
Quando clicar em nova, então abrir form para cadastrar
Quando carregar detalhamento mostrar os dados cadastrados, permitir excluir e salvar
Quando salvar então atualizar os dados da conta
Quando excluir então remover o registro

# API
Apis: http://localhost:8080/contas
Estrutura: id (numero), descricao (string)
